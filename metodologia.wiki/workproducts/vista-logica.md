# Lineamientos

A continuación, se establecen los lineamientos sobre la elaboración del producto de trabajo. Algunos lineamientos base son los siguientes:

1. Se debe utilizar diagramas UML (de preferencia)
2. Se debe agrupar las funcionalidades soportadas por la solución usando paquetes de funciones (de preferencia usar UML)
3. Se debe presentar las funcionalidades usando Caso de Uso (de preferencia y empleando notación UML)
4. Se debe vincular las funcionalidades con los potenciales consumidores.
5. Se debe precisar las restricciones o requisitos que aplican sobre el consumo de las funcionalidades por cada consumidor (protocolos, roles, seguridad, latencia, frecuencia de uso, entre otros). Estos determinan requerimientos no funcionales que deberán ser satisfechos por la solución.
