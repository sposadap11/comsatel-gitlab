# Lineamientos

A continuación se establecen los lineamientos sobre la elaboración del producto de trabajo:

![Componentes del Plan](images/componentes-plan-pruebas.png)

## Sección 1: Objetivos del plan de pruebas

Describe claramente los objetivos que se desean lograr y deben ser específicos, medibles, alcanzables, relevantes y oportunos.

## Sección 2: Alcance de las pruebas

- Defina el alcance del plan de pruebas indicando qué partes del sistema o la aplicación serán probadas
- Cuáles no serán incluidas 
- Especificar los límites de las pruebas y cualquier funcionalidad que se excluya

## Sección 3: Recursos necesarios

Enumera todos los recursos necesarios para llevar a cabo las pruebas como: 
- Personal
- Herramientas de prueba
- Hardware 
- Software 
- Datos de prueba

## Sección 4: Estrategia de pruebas
Describe la metodología general que se utilizará para realizar las pruebas como:
- Pruebas unitarias
- Pruebas de integración
- Pruebas funcionales
- Pruebas de rendimiento
- Pruebas de Regresión

## Sección 5: Cronograma de pruebas

- Establece un calendario que indique cuándo se llevarán a cabo las diferentes fases de pruebas, desde la 
  preparación hasta la ejecución y el informe de resultados

## Sección 6: Procedimientos de prueba

- Detalla los pasos específicos que se seguirán para llevar a cabo las pruebas
- Incluya la configuración del entorno de prueba
- Ejecución de casos de prueba
- Recopilación de datos, etc.

## Sección 7: Riesgos y mitigación

- Identifica los posibles riesgos que podrían afectar el proceso de pruebas y propone estrategias para 
  mitigarlos o gestionarlos
