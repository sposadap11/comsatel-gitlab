# Definiciones y Terminología

- **Control de Acceso**: Procesos que garantizan que solo las personas que necesitan acceso a ciertos activos (digitales) disponen de dicho acceso. Las necesidades se definen en función a los requisitos del negocio y la seguridad.
- **Efectividad**: Medida en que las actividades planeadas se ejecutan de forma específica y se consiguen los resultados o salidas esperadas.
- **Riesgo**: Combinación de probabilidad de ocurrencia de un evento de seguridad de la información y su resultante consecuencia.
- **Tratamiento del riesgo**: Procesos y acciones que reducen los riesgos identificados a un nivel tolerable o aceptable.

# Procedimientos

## [Análisis DAST - Dynamic Analysis Security Testing](seguridad/dynamic-analysis-security-testing)

Este procedimiento tiene por objetivo analizar las aplicaciones Web para identificar de forma oportuna posibles vulnerabilidades de acuerdo con OWASP.

## [Análisis de Componentes Contenerizados](seguridad/analisis-componentes-contenerizados)

Este procedimiento tiene por objetivo analizar los componentes contenerizados para identificar posibles vulnerabilidades de los contenedores basado en **trivy**. 

## Análisis SAST - Static Analysis Security Testing

Este procedimiento tiene por objetivo realizar el análisis del código fuente de los diferentes componentes de nuestras soluciones empleando técnicas de análisis de código a través de [SonarQube](https://sonarqube.qa.comsatel.com.pe/).
