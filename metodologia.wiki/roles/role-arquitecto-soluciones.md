# Responsabilidades

## Principales Tareas

- Diseño y desarrollo de arquitectura y productos software usando arquitectura basadas en servicios (microservicios requerida y/o SOA opcional).
- Diseño de API para microservicios usando plataforma de API Management y documentación basada en Swagger u OpenAPI.
- Desarrollo de código usando scripting con Shell de SO Linux (sh y bash), Python y Go.
- Desarrollo de imágenes de contenedores y cartas Helm Chart para el despliegue de aplicaciones contenerizadas.
- Desarrollo usando CI/CD con productos tales como GitLab, Jenkins (Hudson) o similares.
- Desarrollo de pruebas de conceptos (PoC) que permitan mitigar riesgos y cobertura de requerimientos no funcionales y funcionales.
- Evaluación y propuesta de nuevas tecnologías que permitan satisfacer las necesidades de negocio y requerimientos del software.


## Principales Productos de Trabajo

- Arquitectura Lógica de Referencia de la Solución
- Arquitectura Física de la Solución
- Documento de Diseño de la Arquitectura de la Solución
- Patrones de Integración Empresarial aplicables (EIP)
- Patrones de Diseño Detallado aplicables (GoF)
- Prueba de Concepto Arquitectura
- Architecture Decision Record (ADR)
